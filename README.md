# SummitEdge Solutions

A modern business website built as a responsive landing page for a digital strategy and growth company.

## Features
- Responsive business homepage
- Services, process, testimonials, and contact sections
- Modern dark theme with a professional brand aesthetic
- Mobile-friendly navigation
- Contact form interaction

## Run locally
Open `index.html` directly in a browser, or serve the folder with a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html`
- `styles.css`
- `script.js`
